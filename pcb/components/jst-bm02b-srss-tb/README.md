# JST BM02B-SRSS-TB(LF)(SN)

Private package using upstream KiCad Connector_JST footprint retained in
docs/datasheets (KiCad library CC-BY-SA-4.0 with library exception).
Source geometry compared to JST eSH.pdf pages 1 and 3: top entry,
1 mm pitch, A=1 mm, B=4 mm, body height 4.25 mm. Contact 1 is
left at X=-0.5, contact 2 X=+0.5. Isolated metal hold-down tabs
use separate MP1/MP2 pad numbers so fabrication export can attribute their
copper. They remain separate, optional, unconnected mechanical terminals;
they are not tied together or to ground.
The unavailable legacy WRL reference is omitted, not a verified 3D model.
Speaker harness: pin 1 SPK_P, pin 2 SPK_N; neither wire is ground.
Rated 1 A with AWG28. 0.7 W/8 ohm speaker current is 0.296 A RMS.
